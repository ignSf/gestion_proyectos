Flujos del Sistema

F1
Captura e Ingesta IoT

Sensores → MQTT/TLS 1.3 → API Gateway. Telemetría cada 30 seg con HMAC-SHA256.

F2
Normalización y Buffer

API Gateway → Kafka/Event Hubs (5.000 lecturas/seg) → TimescaleDB Cloud.

F3
Motor de Reglas y Umbrales

Evaluación en ms: Verde (Normal), Amarillo (Ticket < 5 min), Rojo (Alerta < 5 seg).

F4
Dashboard Centralizado

React + GIS/WebGL. Mapas interactivos, gemelos digitales, series temporales.

F5
Gestión de Mantenimiento

ITIL v4. Ciclo de vida de OT, MTTR, balanceo de cuadrillas, reducción OPEX.
